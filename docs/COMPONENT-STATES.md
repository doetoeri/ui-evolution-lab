# Component state applicability

8개 전역 상태 중 해당 컴포넌트에 의미가 없는 상태는 UI에서 명시합니다. Hover·Focus·Active 고정은 시각 시뮬레이션이며 포인터·키보드로 실제 상태도 확인할 수 있습니다. 정보 표시 컴포넌트의 내부 시연 버튼 상태는 별개입니다. 오류는 Text Field 검증과 Toast 동작, 로딩은 Button·Skeleton·Progress 시연으로 실제 실행됩니다.
