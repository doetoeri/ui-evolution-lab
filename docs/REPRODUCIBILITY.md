# 실험 재현성 가이드

평가 버전과 별개로 `environment.search=phase2-search-1.0.0`을 기록합니다. 이전 중간 HTML에서 이 버전이 없던 기록은 열고 내보낼 수 있지만, 부모 적격성 정책이 확정된 현재 엔진으로 재개하지 않습니다. 원자료를 보존하고 새 실험을 시작하세요.

## 저장해야 하는 조건

실험 JSON을 보관하세요. 알고리즘·선택 계열·활성 변수 ID와 순서·예산·반복·seed 목록·GA 개체군·변이율·UCB c·가중치·접근성 제약·화면 크기·캐시·재시도·평가 버전이 함께 들어 있습니다. 전체 유전자·원자료·계산식·실행환경도 기록합니다. CSV는 개별 원자료, summary JSON/CSV는 별도 요약입니다. 스크린샷은 로컬 evidence 폴더도 함께 보관해야 합니다.

## 확정적으로 재현되는 부분

- PRNG는 Mulberry32입니다. 활성 변수 순서는 고정 우선순위와 schema 순서를 조합합니다. 계열 A01은 각 family 블록에서 고정합니다. 120개 선택에서는 A01을 포함해 120개를 기록하지만 119개만 변이 가능합니다.
- 반복 seed는 기본 `baseSeed + repetitionIndex×100003 (uint32)`이며 실제 목록을 설정에 저장합니다. 세 알고리즘은 같은 목록과 family baseline을 공유합니다.
- 동일 family·반복에서 첫 후보는 기본 유전자, 초기 population 구간은 같은 무작위 stream을 사용합니다. 그 뒤 GA의 부모 선택·교차·변이가 난수를 추가 소비해 후보가 달라집니다.
- 고정 예산은 후보 요청 수입니다. 캐시도 1요청이며 재시도는 그 요청에 붙은 기술적 시도입니다. 캐시를 끄면 동일 유전자도 실제로 재평가합니다. 고유 후보·캐시·실행 요청·시도를 따로 기록합니다.
- family → repetition → algorithm 순서이며 알고리즘 순서는 해당 seed로 정한 회전 순서를 사용합니다. 실행시간이 다음 알고리즘의 순서를 바꾸지 않습니다.
- 현재 탐색기의 임의 값 대신 versioned family defaults를 공통 출발점으로 사용합니다. 편집기의 잠금 목록은 실험의 activeVariables 집합과 별개입니다.

같은 config·엔진 버전·평가 응답 sequence라면 후보·UCB 선택·보상·최고점 곡선이 같습니다. Proxy와 Synthetic은 같은 입력에 같은 결과를 반환합니다. 실제 브라우저 관측은 실행환경·폰트·렌더링에 따라 달라질 수 있습니다. 적응형 알고리즘은 관측 점수에 의존하므로 환경이 달라 점수가 바뀌면 후속 후보도 바뀔 수 있다는 한계를 숨기지 않습니다. 시간을 난수 seed나 점수로 사용하지 않습니다.

## GA 방법

2명 tournament로 부모를 고르고 활성 변수별 0.5 확률 uniform crossover를 합니다. 변이는 변수별 확률로 다른 유효 도메인 값을 고릅니다. 선택 연산자 범위에서 하나도 바뀌지 않았다면 적어도 하나를 바꿉니다. 부적격·실패는 적합도 null로 처리합니다. `(μ+1)` steady-state 방식으로 중복 유전자를 합치고 상위 μ개를 보존합니다. 동점이면 먼저 관측한 후보를 유지합니다.

## UCB 방법

| arm | 변수 그룹 |
| --- | --- |
| 색상 | C |
| 레이아웃 | A·B·G·J (A01 고정) |
| 타이포그래피 | D |
| 버튼·컴포넌트 | F |
| 간격·크기·재질 | E·I |
| 모션 | H |

활성 변수가 없는 arm은 제외합니다. 초기 미선택 arm은 위 순서로 한 번씩 사용한 뒤 `meanReward + c√(ln(t)/n)` 최대값을 선택합니다. 동점은 고정 순서입니다. t는 누적 arm 선택 수입니다. 보상은 `max(0,Qchild−Qparent)/100`, [0,1]입니다. 부적격 자식은 0, 적격 부모가 없으면 부모 기준 0을 사용합니다. 교차와 변이가 동시에 작용하므로 보상을 변이 연산자의 인과 효과라고 주장하지 않습니다. n·보상 합·평균 보상을 저장합니다.

## 캐시와 복원

중복 식별에는 seed를 제외한 전체 정규화 유전자 문자열을 사용합니다. 짧은 화면 해시를 유일 키로 쓰지 않습니다. SHA-256은 기록의 genome_hash입니다. 캐시 키는 유전자·목적함수·평가 버전·활성 변수·화면·가중치·접근성 정책·실행기 환경을 포함합니다. seed만 달라도 표현이 같으면 캐시할 수 있습니다.

중지·취소·새로고침 전까지 저장한 결과는 IndexedDB에서 불러옵니다. running 상태로 가져온 파일은 interrupted로 표시합니다. 재개할 때 PRNG와 population을 처음부터 실행하되 기존 응답을 순서대로 재생합니다. 기록된 후보·operator가 새 엔진이 제안한 순서와 다르면 거부합니다. 저장된 기록 이후만 새로 평가합니다. 동일 앱 빌드·Chromium·Node·platform의 evaluator ID를 확인하며, 환경이 다르면 새 실험을 시작합니다.

Phase 1 기록은 원래 4개 arm과 알고리즘별 seed offset을 사용했으므로 새 6개 arm 엔진으로 재개하지 않습니다. 과거 관측은 Synthetic으로 보존합니다.

## 시간과 통계

기록 timestamp는 현재 기록 시각, measurement_timestamp는 원래 관측 시각입니다. 원자료의 measuredAt, 과제별 duration_ms, cache_hit·attempts도 보관합니다. 자동화 시간은 사람의 수행시간이 아니며 목적함수에 넣지 않습니다.

기술통계는 완료 반복의 적격 최고점에 대해 평균·표본 SD(n−1)를 계산합니다. 적격 후보 없는 반복과 중단 반복 수를 별도로 표시합니다. 95% CI는 `mean ± t(.975,n−1)×s/√n`입니다. 독립 반복·근사 정규성을 가정하고 n<2는 계산하지 않습니다. 20보다 큰 자유도는 보수적 t20을 사용합니다. 작은 표본에서는 CI가 넓을 수 있고, 이론적 점수 범위를 벗어나도 임의 절단하지 않습니다.

CI의 겹침·비겹침으로 우월성을 판정하지 않습니다. 가설검정·검정력 분석·다중비교 보정은 수행하지 않았습니다. 변수값별 점수는 탐색 선택 편향과 상호작용이 있는 조건부 관측이므로 인과 효과가 아닙니다. 정상 baseline에서 이미 100점이 나와 모든 최고점 곡선이 평평해지는 경우도 실제 결과로 유지합니다.

참고: [NIST 평균의 신뢰구간](https://www.itl.nist.gov/div898/handbook/eda/section3/eda352.htm). 실험 전에 비교할 seed 목록·가중치·제약·예산을 정하고 결과를 본 뒤 특정 알고리즘만 조건을 바꾸지 마세요.
